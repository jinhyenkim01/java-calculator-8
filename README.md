# 우아한테크코스 프리코스 과제 1: 문자열 덧셈 계산기

입력한 문자열에서 숫자를 추출하여 더하는 계산기를 구현한다.

## 구현 기능 목록

1. 프로그램 실행 시 "덧셈할 문자열을 입력해 주세요."이라는 문구를 출력한다.
1. ~~숫자를 분리하는 구분자를 저장하기 위해 HashMap을 구현하고, 이 때 쉼표(,)와 콜론(:)을 미리 구분자로 지정한다.~~
    1. HashMap 사용 대신, 문자 자체를 character class으로 저장한 후, 커스텀 구분자를 이 character class에 추가하는 방식으로 구분자를 저장한다.
1. 문자열 앞부분의 "//"와 "\n" 사이에 위치하는 문자를 커스텀 구분자로 인식하도록 한다.
1. 구분자를 기준으로 분리한 각 숫자의 합을 반환한다.
1. 잘못된 값을 받는 경우, IllegalArgumentException을 발생시킨 후 애플리케이션을 종료한다.
